# 🐻 BearBearCalc – Ice Bear Calculator

**BearBearCalc** is an ice bear-themed multifunctional calculator website developed using **HTML, CSS, and JavaScript**. It provides a collection of mathematical tools and practical calculation features through a simple, user-friendly interface inspired by an adorable ice bear theme.

The website combines basic mathematical operations, unit conversions, income tax computation, and payroll management into one convenient application.

## 🌐 Live Website

[Visit BearBearCalc](https://dalandanxx.github.io/BearBearCalc/)

## ✨ Features

BearBearCalc offers the following functionalities:

### 1. Unit Converter
Converts measurements between different units:
- **Temperature Conversion:** Celsius (°C) to Fahrenheit (°F) and vice versa.
- **Length Conversion:** Meters (m) to Feet (ft) and vice versa.

### 2. Income Tax Calculator
- Calculates income tax based on the provided income.
- Provides a convenient way to compute tax amounts.

### 3. Natural Numbers Calculator
Performs mathematical operations involving the first N natural numbers:
- **Factorial:** Calculates the factorial of a given number (N!).
- **Sum:** Computes the sum of the first N natural numbers.
- **Average:** Calculates the average of the first N natural numbers.

### 4. Simple Payroll System
Provides basic employee payroll computation and management features:
- Calculates an employee's **gross pay**.
- Computes the employee's **net pay** after applicable deductions.
- Manages and maintains a payroll list of employees.

### 5. Calculation History
- Keeps track of previous calculations.
- Allows users to review their calculation history.
- Makes it easier to refer to previously performed operations.

## 🚀 Getting Started

You can access the website directly through the live link or run a local copy on your computer.

### Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/dalandanxx/BearBearCalc.git
   ```

2. Navigate to the project folder:

   ```bash
   cd BearBearCalc
   ```

3. Open the `index.html` file in your preferred web browser.

No additional installation or dependencies are required.
